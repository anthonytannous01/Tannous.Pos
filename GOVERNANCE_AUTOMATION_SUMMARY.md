# Governance automation — implementation summary

This summarizes **low-risk** guardrails added to enforce existing layering, naming, sync/pagination JSON contracts, observability anchors, OpenAPI surface, financial math drift prevention, and CI gates. It aligns with `.cursorrules`, `ARCHITECTURE_SUMMARY.md`, `CURSOR_RULES.md`, `IMPROVEMENT_REPORT.md`, `GOVERNANCE_REPORT.md`, and `ARCHITECTURE_DEBT_REPORT.md`.

## 1. Implementation summary

- **Architecture & governance tests** live in `tests/Tannous.Pos.Architecture.Tests`, using **NetArchTest.Rules** for dependency direction only (no heavy architecture framework).
- **CI** uses a single **`governance`** job: restore → Release build → `dotnet format --verify-no-changes` → architecture tests → **governance debt scan + budget** → **download prior `governance-debt-report` (PRs, best-effort)** → **`governance/print-debt-summary.ps1`** (Concurrency / Replay / Reconciliation grouping + full table + numeric deltas when previous artifact exists) → run API (Development + dummy connection string) → download OpenAPI → **critical path gate** (OpenAPI + optional `PROBE` HTTP GETs) → artifact uploads (`governance-debt-report`, `openapi-spec`). **`governance/debt-delta.py`** remains available locally; CI deltas are folded into the summary script. **Integration** and **Docker** jobs depend on `governance`.
- **OpenAPI / HTTP:** `governance/critical-openapi-paths.txt` lists path keys that must exist in **swagger.json** (case-insensitive match on the full path string) plus **`PROBE …`** lines for minimal endpoints (e.g. `/api/v1.0/health/ready`) that are mapped explicitly in `Program.cs` and may not appear in Swagger. Swagger path keys follow the versioned explorer format (**`/api/v1/...`** with **PascalCase** controller segments such as `Sync`, `Auth`); mobile `Retrofit` base URLs may still append `v1.0/`. Probes run with `curl` while the API is still up in the same step as spec download — avoids flakiness from a second process boot.
- **OpenAPI schema governance (additive):** `OpenApiSchemaGovernanceTests` + `governance/openapi-schema-governance-baseline.json` assert selected **routes** and **schema property names** for sync pull/push, `OrderDto`, and auth login response remain present (removals / renames / casing drift fail; new optional fields do not).
- **Contract tests:** Wire JSON for settings (`storeName`), pagination (`items`, `page`, `pageSize`, `total`, `totalPages`), sync pull (`cursor`, `upserts`, `deletes`), push (`operationId`, `type`, `payload`), plus existing pagination deserialize and push round-trip tests.
- **Financial governance:** `OrderFinancialGovernance` centralizes the **legacy 10%** tax calculation used by **create** and **finalize** order handlers (high-precision `decimal.Round` with **`MidpointRounding.AwayFromZero`** preserves normal money numerics vs prior inline multiply). ## 3. Governance rules added (tests)

- **Layering:** Domain must not depend on WebApi/Infrastructure; Application must not depend on WebApi; Infrastructure must not depend on WebApi.
- **Controllers:** New `PosDbContext` injection outside allowlist fails CI. New `*Repository` injection outside allowlist fails CI. Non-`Auth` controllers must declare `[Authorize]` at class level. `[AllowAnonymous]` only on `AuthController`.
- **Application naming:** `IRequest<>` types end with `Command` or `Query` (excluding `Behaviors`); `IRequestHandler<,>` types end with `Handler`; `AbstractValidator<>` subclasses end with `Validator`.
- **Contracts:** JSON wire keys for settings, pagination, sync pull/push; ProblemDetails source anchors.
- **Domain anchors:** Stable numeric values for `OrderStatus` and `InventoryMovementType`.
- **Controller routes:** Prefer versioned API routes; legacy allowlist for four controllers.
- **Finalize transactions:** Handler source must retain explicit transaction begin/commit/rollback pattern.
- **Sync replay visibility:** Log strings / governance comments for duplicate `operationId`, missing `operationId`, partial batch outcomes, and per-`Process*` classification (`SyncProcessorGovernanceTests` + `SyncReplayGovernanceSourceTests` + `IdempotencyReplayGovernanceSourceTests` source anchors). **Money-affecting** placeholder processors must retain governance + placeholder + replay/idempotency wording in source.
- **Optimistic concurrency:** `ConcurrencyGovernanceTests` + `ConcurrencyMigrationReadinessGovernanceTests` + baselines — **Order** / **InventoryItem** / **Shift** enforce **`RowVersion`** (see **`OptimisticConcurrencyInfrastructureGovernanceTests`**, integration **`OptimisticConcurrencyIntegrationTests`** with Docker). Hard fail only on baseline retention rules.
- **Money-path anchors:** `MoneyPathGovernanceSourceTests` locks finalize/void/financial-governance source strings (complements `FinalizeOrderTransactionGovernanceSourceTests` and invariant anchors).
